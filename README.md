# Sift Dimension Mod

Explore the Sift Dimension with unique ores, armor, and portal puzzles in Minecraft 1.21.4.

## Features

- Adds a new dimension called Sift Dimension with a portal puzzle
- Includes Siftite ore mining and crafting system
- Features Siftite armor with custom recipes and properties

## Requirements

- Minecraft 1.21.4
- Fabric Loader 0.15.7 or later
- Fabric API

## Installation

1. Download the mod from the [releases page](https://github.com/EnderDevelopment/sift-dimension-mod/releases).
2. Place the mod file in your `mods` folder.
3. Launch Minecraft with the Fabric profile.

## Usage

### Creating the Sift Dimension Portal

1. Craft the portal frame using Siftite blocks and other materials.
2. Activate the portal by interacting with the frame.

### Mining Siftite Ore

1. Use a Siftite pickaxe to mine Siftite ore.
2. Smelt the ore to obtain Siftite ingots.

### Crafting Siftite Armor

1. Combine Siftite ingots with leather or other materials to craft Siftite armor pieces.
2. Equip the armor for enhanced protection.

## Configuration

The mod includes a configuration file located at `config/siftdimensionmod.json`. You can adjust various settings such as ore spawn rates, armor properties, and portal requirements in this file.
